The [employer directory](job_radar/seeds.py) contains 182 companies after the [HCMC exclusions](EMPLOYER_SCOPE.md). The other 55 companies have no built-in feed. No placeholder jobs are created for missing sources.

The original 115-company cohort records 55 accepted integrations, 53 blocked targets, 5 pending targets, 1 adapter awaiting verification, and 1 implementation awaiting verification. These acceptance statuses do not replace runtime evidence.

The audit ran all 25 feeds added since the interns' handoff. After corrections, 14 returned complete job descriptions, seven returned no matching postings, and four failed external HTTP/TLS access. Zero matching jobs do not prove that posting extraction works. Access failures remain visible errors; TLS verification stays enabled.

FPT Software uses its current public Angular backend API with zero-based pagination. MB Life, Mirae Asset and Hyundai use Talentnetwork posting descriptions and job-specific metadata. Workday feeds check Vietnam locations or country facets. Bao Viet and Public Bank publish several positions in one announcement; their collectors retain separate role identities while application destinations remain the original official page or published HR email.

Feed definitions: [job_radar/feed_catalog.py](job_radar/feed_catalog.py). Collector dispatch: [job_radar/collectors.py](job_radar/collectors.py). Explicit past application deadlines are skipped. Collector contract and dedup tests run on feature-branch CI; live HTTP probes remain available through the separate career-feed workflow.
